# PG2 - Computer Graphics 2

*Počítačová grafika 2*

OpenGL 4.x core profile rendering engine in C++.

## Topics & Features:
* **OpenGL 4.x Core Profile & GLSL:** Modern shader pipeline (vertex, fragment)
* **Camera System:** First-person and arcball camera using quaternions and Euler angles (yaw, pitch)
* **Mesh & Scene Loading:** OBJ model loading with vertex normals and texture coordinates
* **Lighting & Shading:** Physically Based Rendering (PBR) using Cook-Torrance BRDF and GGX microfacet distribution
* **Advanced Rendering:** Deferred shading and shadow mapping
