Cíl

Cílem tohoto cvičení je rozšířit váš operační systém o podporu hardwarových přerušení (interrupts) a využít je pro implementaci časovače (timer interrupt).

Po dokončení bude váš OS schopen:

  • inicializovat tabulku přerušení (IDT)
  • registrovat vlastní obslužné rutiny (ISR – Interrupt Service Routine)
  • zpracovávat přerušení z časovače (IRQ0)
  • periodicky přerušovat běh kernelu
  • napojit časovač na váš plánovač (scheduler_tick())

Tímto krokem přecházíte od kooperativního plánování k základům preemptivního multitaskingu.

Můžete se inspirovat/převzít některé ISR rutiny z os-tutorial

Kontext

V předchozích úlohách jste implementovali:

  • běh kernelu v protected mode
  • ovladače (VGA, serial, keyboard, ATA)
  • CLI
  • vlastní plánovače (RR, priority, lottery)

Plánovač je nyní spouštěn explicitně (např. yield). V této úloze zajistíte, že bude spouštěn automaticky pomocí časovače.

Co je přerušení?

Přerušení je mechanismus, kterým hardware přeruší běh CPU a předá řízení speciální funkci (ISR).

Na architektuře x86:

  • přerušení jsou směrována přes IDT (Interrupt Descriptor Table)
  • každé přerušení má své číslo (0–255)
  • hardware IRQ jsou mapovány přes PIC (Programmable Interrupt Controller)

Úkol 1: IDT (Interrupt Descriptor Table)

Implementujte:

  • strukturu položky IDT (IDT entry)
  • pole IDT (256 položek)
  • funkci pro nastavení handleru:
void idt_set_gate(int n, uint32_t handler);
  • strukturu IDTR (pro instrukci lidt)
  • načtení IDT:
void idt_load();

Požadavky:

  • IDT musí být zarovnaná a správně inicializovaná
  • používejte interrupt gate (typ 0x8E)
  • segment selector nastavte na kernel code segment (např. 0x08)

Úkol 2: ISR (Interrupt Service Routines)

Vytvořte:

  • assembler wrapper pro ISR (uložení registrů)

např.:

isr_common_stub:
    pusha
    call isr_handler
    popa
    iret
  • C handler:
void isr_handler();

Doporučení:

  • oddělte:

    • low-level ASM stub
    • high-level C handler

Úkol 3: PIC (8259) – remapování IRQ

Defaultně se IRQ překrývají s CPU výjimkami → je nutné je přemapovat.

Implementujte:

void pic_remap();

Nové mapování:

  • IRQ0–IRQ7 → 32–39
  • IRQ8–IRQ15 → 40–47

Nezapomeňte:

  • posílat EOI (End Of Interrupt):
outb(0x20, 0x20);

(případně i pro slave PIC)

Úkol 4: Časovač (PIT – Programmable Interval Timer)

Použijeme PIT (IRQ0) pro generování pravidelných přerušení.

Implementujte:

void timer_init(uint32_t frequency);

Nastavení:

  • PIT frekvence: 1193180 Hz
  • např. 100 Hz → každých 10 ms

Úkol 5: Timer ISR

V ISR pro časovač:

void timer_callback()
{
    tick++;

    scheduler_tick();   // napojení na váš plánovač
}

Požadavky:

  • ISR musí:

    • být rychlá
    • neobsahovat blokující operace
    • nezapomeňte na EOI

Úkol 6: Napojení na plánovač

Použijte připravené rozhraní:

void scheduler_tick();

Cíl:

  • místo ručního yield() bude plánování řízeno časovačem
  • systém začne „sám“ přepínat vlákna

Testování

Po implementaci by měl systém:

  • inicializovat IDT
  • zapnout přerušení (sti)
  • periodicky generovat tick

Test:

  • vypisujte tick counter (např. na serial)
  • spusťte více vláken
  • ověřte, že se přepínají bez explicitního yield

  • implementace systémového času (uptime)
